**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 记录目标主机资源、单后端 worker、SQLite 单实例和持久化条件，并保留受控调用方边界。
- [ ] 记录 TLS 入口、管理网络范围、Next.js 到后端路径，以及 Direct Route 和 HTTP/HTTPS/SOCKS 代理路径与协议；未决安全细节显式标出。

- [ ] 取得部署方确认；将缺失外部条件保留为验证阻塞，并追踪 SRS-F-028、033、034、036、039、040 及 TBD-05、TBD-09、TBD-10、TBD-11；环境批准不等于安全检查或真实冒烟通过。
