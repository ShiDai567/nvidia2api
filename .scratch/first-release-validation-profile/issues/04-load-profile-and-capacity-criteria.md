# 04: 批准目标负载画像与容量验收口径

**What to build:** 形成运营方批准的目标负载画像和容量验收口径，为资源设计及后续压力测试提供共同目标，但不宣称容量已达标。

**Blocked by:** 01: 确定代表性调用场景与必验组合; 02: 明确目标部署环境与真实验证前提

**Status:** ready-for-agent

- [ ] 记录典型与峰值请求量或并发、短请求与长流比例、流持续时间、输入输出规模、模型分布及可用上游配额，并关联场景和环境。
- [ ] 延迟、错误率、可用性等目标注明适用条件、统计口径、单位、测量窗口、责任方和批准状态；目标值由运营方确认，不自行编造。
- [ ] 分开记录业务负载目标、请求体/并发/线路数/连接/超时等资源配置候选值和实测结论。
- [ ] 说明竞速实际启动线路会放大上游请求消耗；不假设取消可以撤销额度或费用。
- [ ] 明确目标与 Key/代理、上游配额和单机边界的冲突处理；输入缺失或未批准时保持阻塞。
- [ ] 追踪 SRS-F-033、035、039 及 TBD-04、TBD-05、TBD-09；批准目标不等于压测通过，也不关闭要求实测的 TBD。
