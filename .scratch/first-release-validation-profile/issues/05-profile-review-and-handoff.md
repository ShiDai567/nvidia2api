**Blocked by:** 03: 定义必验组合的预期行为与支持证据规则; 04: 批准目标负载画像与容量验收口径

**Status:** ready-for-agent

- [ ] 每个必验组合可定位场景、模型、客户端版本、预期行为或明确决策问题、目标环境、负载条件和证据要求；不存在未说明假设或互相矛盾的结论。
- [ ] 将模型/客户端特有的真实验证前提与环境登记核对；缺少凭据、额度或时段仅登记为后续验证阻塞，不掩盖未作出的目标选择。
- [ ] 追踪相关 SRS/TBD，重点涵盖 TBD-01 至 TBD-05、TBD-09 至 TBD-11；将 TBD-06 至 TBD-08 保留为数据、安全和恢复目标的交接输入。目标填写不替代测试或演练通过。
- [ ] 对未决事项记录责任方、影响、关闭条件和下游归属，并区分画像目标阻塞与后续验证阻塞；目标场景、环境或负载未批准时不得宣告画像完成。
- [ ] 保留候选目标依赖 DAG：画像为竞速生命周期、资源策略和兼容策略提供输入，安全边界可并行推进；不批量建立新地图或后续决策票。
- [ ] 走查未验证能力、版本变化、仅模拟证据、缺额度和未压测目标等反例，确认批准、验证和支持承诺没有混淆。
- [ ] 完成画像整体评审和交接结论；材料可用于编写验证计划，但不宣告首发可发布、不缩减 SRS 首发功能范围。
